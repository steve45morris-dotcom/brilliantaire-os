## Claude Code MCP Configuration

Add the following to your Claude Code MCP settings file.

### Option 1: Project-Level (`.mcp.json` in project root)

```json
{
  "mcpServers": {
    "local-inference": {
      "command": "node",
      "args": ["dist/scripts/local-inference.js"],
      "env": {
        "LOCAL_INFERENCE_ENABLED": "true",
        "LOCAL_INFERENCE_URL": "{{SERVER_URL}}"
      }
    }
  }
}
```

### Option 2: User-Level (`~/.claude/settings.json`)

```json
{
  "env": {
    "LOCAL_INFERENCE_URL": "{{SERVER_URL}}",
    "LOCAL_INFERENCE_MODEL": "{{MODEL}}"
  }
}
```

### Option 3: Environment Variable Approach

Set these in your shell profile (`~/.zshrc` or `~/.bashrc`):

```bash
export LOCAL_INFERENCE_URL="{{SERVER_URL}}"
export LOCAL_INFERENCE_MODEL="{{MODEL}}"
export LOCAL_INFERENCE_ENABLED="true"
```
