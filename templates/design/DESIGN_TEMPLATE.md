# 1. Product identity

Name, offer, route, and product category.

# 2. Business objective

The measurable business outcome this interface supports.

# 3. Audience

Primary audience, context, needs, and constraints.

# 4. Brand personality

Three to five traits plus the intended emotional direction.

# 5. Visual references

References, what to learn from each, and what not to copy.

# 6. Typography system

Display, body, utility roles; sizes; weights; line heights; fallbacks.

# 7. Color system

Canvas, surface, text, border, action, status roles with values and contrast intent.

# 8. Spacing scale

Approved spacing values and usage rules.

# 9. Grid and layout

Container widths, columns, gutters, section rhythm, and collapse behavior.

# 10. Components

Required components, states, density, and ownership.

# 11. Borders and radius

Border roles, widths, and radius scale.

# 12. Elevation and shadows

Surface hierarchy and permitted shadows.

# 13. Icons

Icon family, sizes, stroke rules, labels, and tooltips.

# 14. Photography and artwork

Subject, composition, crop, authenticity, licensing, and forbidden imagery.

# 15. Motion

Purpose, duration, easing, reduced-motion behavior, and limits.

# 16. Responsive rules

Desktop, tablet, and mobile layout and interaction changes.

# 17. Accessibility rules

Contrast, focus, keyboard, semantics, touch target, and motion requirements.

# 18. Conversion hierarchy

Primary action, supporting actions, proof, objections, and order.

# 19. Forbidden patterns

Project-specific prohibitions plus the standard forbidden defaults.

# 20. Acceptance criteria

Required score, evidence paths, route contract, functional checks, and reviewer independence.
