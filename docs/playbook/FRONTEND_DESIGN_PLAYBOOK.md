# Frontend Design Playbook

1. Read the workspace profile and corresponding design system before editing UI.
2. Write or validate DESIGN.md and define the page's single primary job.
3. Audit route truth, existing components, tokens, responsive behavior, and real assets.
4. Choose one subject-specific signature element; keep supporting UI restrained.
5. Reuse approved components selectively and record provenance.
6. Implement with stable responsive constraints, visible focus, semantic states, and reduced motion.
7. Capture desktop and mobile evidence outside source folders.
8. Score with the visual rubric and cite evidence for every category.
9. Fix the highest-impact defect first; recapture regression evidence.
10. Accept only after an independent review meets the threshold with no blockers.

Platform consistency governs behavior, accessibility, navigation logic, status feedback, and interaction quality. Workspace branding governs typography, color, imagery, art direction, content hierarchy, and marketing tone.
