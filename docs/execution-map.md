# Execution Map

## Default Weekly Rhythm

### Monday: Command

Review priorities, pick 3 outcomes, clear blockers, assign work to OS lanes.

### Tuesday: Build

Work on Labs, tools, pages, automations, systems, or dashboards.

### Wednesday: Package

Turn rough work into offers, content, landing sections, case studies, templates, or campaign assets.

### Thursday: Publish

Release content, build logs, visual assets, music clips, strategy posts, or product updates.

### Friday: Network

Contact collaborators, artists, founders, brands, communities, and possible clients.

### Saturday: Music/Media

Record, perform, shoot, edit, test visual concepts, plan rollouts.

### Sunday: Review

Measure what worked, update the OS, archive weak ideas, choose the next week.

## Output Targets

Every week should produce at least:

- 1 system improvement
- 1 public proof-of-work post
- 1 music/media asset or campaign asset
- 1 business/revenue action
- 1 learning/research note

## Decision Filter

Before adding a project, ask:

1. Does this strengthen the ICYFLAMZE identity?
2. Does this create proof of skill?
3. Does this create audience, money, leverage, or learning?
4. Can it become a reusable system or asset?
5. Is it aligned with the Brilliantaire mission?
