# Project Design Profiles

These profiles define brand autonomy above the shared interaction and accessibility foundation. Machine-readable records live in `src/design/DesignProfiles.ts`.

| Project | Audience | Brand / emotion | Type / color / imagery | Conversion goal | Prohibited patterns | Minimum |
|---|---|---|---|---|---|---:|
| The One System | Project and agent operators | Calm command authority; trustworthy system state | Technical grotesk + mono; neutral ink and semantic status; real evidence | Reach the correct operational action | Marketing hero, fake telemetry, generic AI imagery | 80 |
| Icyflamze | Listeners, collaborators, creative operators | Cold precision and controlled flame; singular Nigerian hip-hop world | Monumental display; cyan/orange/gold/black; original artist/release media | Play, follow, or enter the workspace | Generic musician template, unverified proof | 90 |
| ProfBetGeng | Sports bettors managing ticket risk | Analytical energy and disciplined confidence | Condensed sports display; pitch green/cyan/gold/risk red; real tickets and matches | Convert a ticket or start risk review | Casino noise, meaningless win statistics | 85 |
| TreeGroove Records | Artists, label operators, distributors | Grounded, rhythmic, independent | Editorial display; forest/charcoal/paper/red; artist and catalog photography | Review catalog or start release workflow | Identical release grids, generic music stock | 85 |
| Joy Beauty Studio | Local beauty clients | Polished warmth and confident care | Editorial serif + crisp sans; ink/petal/mineral/white; honest service photography | Book a specific service | Beige luxury template, script overload, fake testimonials | 85 |
| Avatar | Creative producers managing personas | Cinematic craft and technical control | Wide display + mono metadata; black/silver/render blue; real rigs and frames | Review or approve a render stage | Faceless synthetic portraits, decorative sci-fi HUD | 85 |
| Podcast | Hosts and editors | Focused, intimate, articulate | Humanist sans + mono timecode; warm white/graphite/red/blue; real hosts and waveforms | Ingest, edit, or publish an episode | Decorative fake waveform, generic microphones | 85 |
| AI School | Practical AI builders | Curious, direct, rigorous | Textbook serif + code mono; white/carbon/cobalt/yellow; real diagrams and code | Start or continue a lesson | Robot heads, meaningless AI gradients | 85 |
