# Visual Acceptance Rubric

Visual acceptance is separate from build and test success. Score each category from 0 to 10 and attach evidence for every score.

| Category | Points | Evidence examples |
|---|---:|---|
| Brand distinction | 10 | DESIGN.md alignment, identifiable visual signature |
| Typography | 10 | type tokens, hierarchy, wrapping at target viewports |
| Layout hierarchy | 10 | screenshot and task-flow inspection |
| Spacing consistency | 10 | token use and rhythm review |
| Color discipline | 10 | semantic roles and contrast checks |
| Imagery and visual interest | 10 | authentic assets, useful visual content |
| Responsive behavior | 10 | desktop, tablet where practical, and mobile evidence |
| Interaction quality | 10 | navigation, hover, focus, modal, loading/error states |
| Accessibility | 10 | keyboard, semantics, focus, contrast, reduced motion |
| Conversion clarity | 10 | obvious primary action and supporting hierarchy |

Thresholds: internal operational screen 80; business landing page 85; flagship public landing page 90.

Rules: a successful build or passing test suite is not visual acceptance; desktop does not imply mobile; the implementing agent cannot silently award a perfect score; every score needs evidence; every score below threshold requires revision; every unresolved blocker prevents acceptance; independent verification is mandatory.
