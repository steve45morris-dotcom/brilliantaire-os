# Visual Language Guide

This document defines the strict visual rules for the **ICYFLAMZE CORE** universe.

---

## 🎨 Color Palette
- Base Black (#0A0A0A): Midnight depths representing absolute system privacy.
- Metallic Gold (#D4AF37): Royalty, value, legacy building.
- Neon Blue (#00E5FF): AI integration, code lines, terminal routing guides.

## 💡 Lighting Rules
- High-contrast chiascuro lighting.
- Cyber-street scenes showing rain-slicked docks reflecting neon blue and gold rays.
- Silhouette character portraits backlit by transparent interface panels.

## 🕶️ Outfit Rules
- Black matte technical coats with custom gold engraving.
- Minimalist tactical straps and gear.
- Cybernetic specs displaying command diagnostics in neon-blue overlays.

## 🏙️ Environment Rules
- Concrete urban alleyways under dark stormy skies.
- Industrial server rooms with gold cabling and blue status nodes.
- Elevated golden throne mainframes overlooking high-contrast grid layouts.

## 🎬 Anime/3D Style Rules
- Highly detailed cinematic 2.5D anime style.
- Dark, grit-textured concrete structures mapping cleanly against clean digital panels.

## 🎥 Camera Rules
- Overhead bird's-eye views parsing city street blocks like chessboard patterns.
- Macro focus shots on lighter ignitions and hand-placed chess items.

## ✏️ Typography Rules
- Monospace fonts (Courier/JetBrains) for terminal screens.
- Clean modern sans-serif fonts (Inter/Outfit) for graphic overlays.

---

## 🚫 Do-Not-Use Rules
- **No Generic Superheroes:** Avoid spandex, capes, or random energy-throwing battles.
- **No Generic Space Sci-Fi:** Avoid space helmets, spacecraft, or generic space suits.
- **No Generic Afro-Futurism:** Do not use generic tribal masks or patterns; focus strictly on Street Scholar elements.
- **No Random Tech Clutter:** Do not add meaningless wires or random buttons. Every screen must represent clean data.
