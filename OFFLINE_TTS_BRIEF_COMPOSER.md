# 🎙️ Offline TTS Brief Composer

## 🌌 Purpose
The **Offline TTS Brief Composer** compiles citation-backed, manual-reviewed narrator briefs into TTS-ready script documents, audio queue packets, and voice directions without generating sound files. This decouples formatting and scripting logic from the actual speech synthesis engine, enforcing strict offline validation.

---

## 🛠️ Safety Boundaries & System Constraints
This processor runs under the following offline boundaries:
1. **Composer-Only Mode:** Script compilation and formatting only. No TTS engine execution (e.g. Piper, say) and no raw audio file creation.
2. **No TTS Generation:** Under no circumstances should audio assets be generated during this phase.
3. **No External APIs:** No network operations, cloud voices, or external API lookups.
4. **No Obsidian writes:** The outputs are localized to the system repository's staging folders.
5. **No Graph edits:** This phase consumes narrator briefs and does not modify the grounded index graph.
6. **Command Router Gate:** Command execution is routed through exact-name gates to prevent unconfirmed runs.

---

## 📂 Directories Mapping

### Input Files
- Grounded Narrator Briefs: `outputs/grounded_narrator/briefs/`
- Grounded Review Queue: `outputs/grounded_narrator/review_queue/`
- Grounded Rejected/Exclusions: `outputs/grounded_narrator/rejected/`

### Output Files
- Scripts: `outputs/tts_briefs/scripts/`
- Queue Packets: `outputs/tts_briefs/queue_packets/`
- Voice Directions: `outputs/tts_briefs/voice_directions/`
- Audit Logs: `outputs/tts_briefs/logs/`

---

## 📊 Supported Script Lengths & Words Limits
- **Short Script:** Max 150 words. Focuses on brief alerts and single core takeaways.
- **Medium Script:** Max 450 words. Outlines up to 5 core points and practical interpretation.
- **Long Script:** Max 900 words. Deep dive narrative arc, core insights, workflow implications, and risk notes.

---

## 🎭 Voice Direction Profiles
The composer supports the following tone profiles:
- `calm analyst`: Structured, moderate pace, precise pronunciation.
- `strategic narrator`: Authoritative, slow pace, high impact emphasis.
- `energetic briefing`: Fast-paced, dynamic emphasis, high-level highlights.
- `oracle voice`: Reverb-ready, cinematic tone, slow pacing.
- `campaign command voice`: Gated command tone, dynamic emphasis.

## ⌨️ Command Reference

Execute commands through the Safe Command Router:

### Help Menu
```bash
npm run command -- "tts-brief-composer-help"
```

### Compile Short Script
```bash
npm run command -- "tts-brief-composer short"
```

### Compile Medium Script
```bash
npm run command -- "tts-brief-composer medium"
```

### Compile Long Script
```bash
npm run command -- "tts-brief-composer long"
```

### Compile All Script Styles
```bash
npm run command -- "tts-brief-composer all"
```

### Compile TTS Queue Packet
```bash
npm run command -- "tts-brief-composer queue-packet"
```

### Compile Voice Direction Spec
```bash
npm run command -- "tts-brief-composer voice-direction"
```

### Check Composer Status
```bash
npm run command -- "tts-brief-composer status"
```

## 🔮 Future TTS Generation Boundary
Once the scripts and queue packets generated by this composer are manually reviewed and approved by the operator, they can be processed by the rendering engine in a subsequent audio synthesis execution phase.
