# 🥾 Installation Guide: Version 1.0.0
\`Status: Locked\`

Detailed guidelines for setting up IcyOS in local environments.

---

## 📋 Steps
1. **Prerequisites**: Node.js v20+, pnpm package manager.
2. **Commands**: Run \`pnpm install\` at root directory to pull monorepo dependencies.
3. **Build**: Run \`pnpm build\` to compile TS packages.
