# ADR-0007: Icy CLI
- **Status**: Accepted
- **Date**: 2026-07-02
- **Author**: Principal AI Governance Architect

---

## Context & Problem
We need a unified interface wrapper to execute preflight checks, sandbox setup, and completion summaries automation.

## Proposed Solution
Design and adopt the `icy` CLI Specification (`16 Scripts/icy CLI Specification.md`) as the future command gateway.

## Alternatives Considered
- **Raw shell script commands execution**: Complicated and hard for AI agents to call cleanly.

## Consequences
- **Positive**: Standardized interface, simple inputs boundaries.
- **Negative**: Initial build costs for CLI scripts.
