# 📊 Metrics Specification
\`Status: Active\` | \`Scope: Metrics\`

This document defines core system metric logs and names.

---

## 📋 System Metric Counters

- `icyos.cache.hit_rate`: Frequency of Context cache hits.
- `icyos.sync.latency_ms`: Duration of Google Calendar and Obsidian sync processes.
- `icyos.notifications.delivered`: Count of alerts successfully pushed.
- `icyos.sessions.overrun_ms`: Amount of focus overrun consuming buffers.
