# 📊 Telemetry Framework
\`Status: Active\` | \`Scope: Telemetry\`

## 📋 Tracked Metrics

1. **AI Acceptance rate**: Tracks user approval or rejection of generated plans.
2. **Focus Duration**: Records active focus block session lengths.
3. **Connector Sync Failures**: Logs Google/Apple sync latency anomalies.
