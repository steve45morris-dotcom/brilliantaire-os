# 🔤 Naming Standards: Database & Schema Keys
`Version: 1.0.0` | `Status: Active` | `Scope: Information Architecture`

Naming guidelines for database tables, indexes, keys, and documents.

- **Tables names**: Use `snake_case` plural (e.g. `users`, `workspaces`, `projects`).
- **Columns names**: Use `snake_case` singular (e.g. `created_at`, `root_path`).
- **Foreign Keys**: `[parent_singular]_id` (e.g. `workspace_id`).
- **Primary Keys**: `id` (UUID).
