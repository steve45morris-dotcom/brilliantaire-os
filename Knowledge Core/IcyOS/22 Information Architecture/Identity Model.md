# 🔑 Identity Model & Identification Schemas
`Version: 1.0.0` | `Status: Active` | `Scope: Information Architecture`

Identity model rules for logical entities, database keys, and specification files.

---

## 📐 Identifier Standards
- **Database Primary Keys**: Must strictly utilize **UUIDv4** keys.
- **Specification Documents**: Prefix-Slug formats (e.g. `ADR-0001`, `DEC-001`, `TSK-101`).
- **Sandbox Mission Folders**: `msn-[sprint-id]-[UUID]/` for directory isolation.
