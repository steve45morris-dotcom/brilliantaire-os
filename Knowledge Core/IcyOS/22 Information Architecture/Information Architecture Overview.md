# 🌐 Information Architecture Overview
`Version: 1.0.0` | `Status: Active` | `Scope: Information Architecture`

This document details the mapping guidelines, validation gates, and information structures of **IcyOS**.

---

## 🧭 System Schema Layers
Information architecture maps business entities directly to PostgreSQL tables, REST payloads, and JSON document structures using:
1. **Normalized Tables (Structured SQL)**: Users, Workspaces, Projects, Sprints, and Timelines.
2. **Dynamic JSON Blocks (Semi-structured Document)**: Staged mission changes, AI context packages, and logs.
3. **Markdown spec Nodes (Obsidian Local Vault)**: Blueprints, ADRs, and guidelines.
