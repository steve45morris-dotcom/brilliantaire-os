# 🧱 Component System Overview
`Version: 1.0.0` | `Status: Active` | `Scope: Component System`

This document details the frontend component boundaries, properties contracts, and layouts of **IcyOS**.

---

## 📐 Component Layering Model
Components are partitioned into 4 distinct layers:
1. **Primitives**: Atom-level buttons, pills, status indicators, badges.
2. **Layout & Navigation**: App shells, sidebars, bottom navigation.
3. **Data Display**: Timeline grids, mission list items.
4. **Domain/AI Modules**: Intent consoles, approval panels, focus timers.
