# 🌐 IcyOS Domain Overview
`Version: 1.0.0` | `Status: Active` | `Scope: Domain Model`

This document outlines the Domain-Driven Design (DDD) boundaries, core subdomain classifications, and architectural patterns of **IcyOS**.

---

## 🧭 Domain Topology
IcyOS is partitioned into four major subdomain areas:
1. **Core Domain (Intelligent Loop)**: Planning, timeline scheduling, focus execution, and adaptive learning (VNP, VibeVoice, engine routing).
2. **Supporting Subdomain (Knowledge & Decisions)**: Obsidian note mappings, ADR logs, tag taxonomies, and index syncs.
3. **Generic Subdomain (Infrastructure)**: Git repository file structures, PostgreSQL configurations, BullMQ job queues, and security gates.
