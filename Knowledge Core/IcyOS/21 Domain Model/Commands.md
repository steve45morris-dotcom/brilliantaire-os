## 🗂️ Commands Catalog
- **`CreateMission`**: Stage a new task package.
- **`ApproveTimeline` / `RejectTimeline`**: strategists validation gate operations.
- **`StartSession` / `CompleteSession`**: AI preflight and wrap-up execution protocols.
- **`SkipMission`**: Reschedule pending tasks.
- **`GenerateBriefing`**: Compile current Sprint status summaries.
- **`GenerateReview`**: Audit staging code linter validations.
- **`IncreaseTrust` / `DecreaseTrust`**: Restructure agent permissions limits.
- **`BuildContextPackage`**: Build task-specific files references.
