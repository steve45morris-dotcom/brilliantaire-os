# 💎 Value Objects Specification
`Version: 1.0.0` | `Status: Active` | `Scope: Domain Model`

Immutably modeled attributes and state variables used across entities.

---

## 🗃️ Value Objects List
- **Priority**: Scale of `P1` (critical override), `P2` (sprint target), `P3` (backlog item).
- **Energy Level**: User capacity score (`High`, `Medium`, `Resting`).
- **Time Estimate**: Duration bounds in minutes (`estimated_min`, `maximum_min`).
- **Focus Score**: Daily concentration metrics (`0` to `100`).
- **Completion Score**: Percentage progress tracking of tasks (`0` to `100`).
- **Confidence Score**: AI assurance validation scoring (`0.0` to `1.0`).
- **Mission Status**: Lifecycle flags (`Staged`, `Approved`, `Running`, `Completed`, `Skipped`).
- **Session Status**: Run status indicators (`Active`, `Wrapped`, `Failing`).
