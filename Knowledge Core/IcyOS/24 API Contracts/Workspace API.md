# 🌐 Workspace API
`Version: 1.0.0` | `Status: Active`

REST mappings for workspaces resource.

- **Endpoints**:
  - `GET /workspaces`: Retrieve workspaces lists.
  - `POST /workspaces`: Register a root directory.
  - `DELETE /workspaces/:id`: De-register a directory.
