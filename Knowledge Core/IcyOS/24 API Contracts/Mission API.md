# 🌐 Mission API
`Version: 1.0.0` | `Status: Active`

REST mappings for missions resource.

- **Endpoints**:
  - `GET /missions`: Retrieve missions list.
  - `POST /missions`: Stage a mission.
  - `PATCH /missions/:id/status`: Update state.
