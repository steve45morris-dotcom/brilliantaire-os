# 📡 Realtime Events Contract
`Version: 1.0.0` | `Status: Approved` | `Scope: API Contracts`

Realtime events broadcasted via Supabase Broadcast Channels.

---

## 🗂️ Event Channel Topics
- **`mission.started`**: Broadcasts when a staged task starts.
- **`mission.completed`**: Broadcasts when validations check passes.
- **`mission.skipped`**: Broadcasts when reschedule calls trigger.
- **`timeline.regenerated`**: Broadcasts when calendar blocks shift.
- **`session.started`** / **`session.completed`**: Broadcasts active running details.
- **`review.generated`**: Broadcasts compile test results.
- **`recommendation.created`**: Broadcasts new backlog suggestions.
- **`trust.updated`**: Broadcasts updated trust score metrics.
- **`briefing.generated`**: Broadcasts current sprint briefings reports.
