## 📅 Post-Session Log Template
Upon finishing a strategic milestone, write a log file into `15 Daily Notes/` matching this format:

```markdown
# Session Log: {{date:YYYY-MM-DD}} - [Sprint Target]
`Status: Complete` | `Author: [Agent Name / Role]`

## 🚀 Shipped Deliverables
- [x] Description of code written or folder notes created.

## ⚖️ Strategic Decisions & ADRs
- Link newly added ADRs.

## 💡 Lessons Learned & Pitfalls
- Document bugs, path conflicts, or dependency errors solved.
```
