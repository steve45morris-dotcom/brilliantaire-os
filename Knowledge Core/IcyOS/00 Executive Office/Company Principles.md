# 🛡️ ICOS Company Principles
`Version: 1.0.0` | `Status: Active`

## 💎 Core Principles
1. **Design Before Action (Architect-Core)**: Spec sheets, blueprints, and schemas govern code. Implementation never starts without validated designs.
2. **Context Persistence**: The knowledge base must remain self-documenting. A developer or AI should be able to drop in and pick up the workspace instantly without relying on historical chat feeds.
3. **Rest as an Operating Priority**: Scheduling engines must respect and protect user rest buffers, treating human strategic focus as the company's highest leverage asset.
