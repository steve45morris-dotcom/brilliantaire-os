## 🏛️ Decision Matrices

### 1. Scope vs. Capacity Blocker
- **Trigger**: Sprint workload exceeds human focus availability.
- **Rule**: Defer secondary features to the backlog. Never squeeze protected rest buffers.

### 2. Autonomy Limits Check
- **Trigger**: An agent worker proposes running a system command outside local folders.
- **Rule**: Interrupt and gate behind the **Sentinel Safety Gate** for manual command approval.
