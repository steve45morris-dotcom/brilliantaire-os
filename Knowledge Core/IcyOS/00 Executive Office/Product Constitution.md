# 📜 Product Constitution: Core Laws of IcyOS
`Version: 1.0.0` | `Status: Active` | `Scope: Global`

This constitution outlines the immutable laws governing the IcyOS software ecosystem. All AI planners, user interfaces, data managers, and backend engines must comply with these laws.

---

## 🏛️ The Five Constitutional Laws

### Law 1: Strategic Human Sovereignty
The human strategist is the ultimate authority. No AI agent may make destructive, financial, structural, or external network commitments without an explicit human approval action (the "Human-in-the-Loop" gate).

### Law 2: Permanent Memory Integrity
All system knowledge, task lists, and core parameters must live in the Obsidian Knowledge Core. Database storage is secondary and acts as an index/execution cache. If a conflict occurs, the Obsidian document state is the definitive source of truth.

### Law 3: Zero Context Loss
Every code module must be self-documenting, and every execution step must leave behind a readable trace in the Memory logs. The codebase must remain compatible across multiple different AI clients (Cursor, Claude Code, Antigravity, Gemini CLI) without relying on chat history.

### Law 4: Protected Buffer Sovereignty
User buffers (rest times, deep work cycles, physical focus blocks) are sacred. The planning and calendar engine cannot schedule tasks or prompt the user during these blocks unless a Critical Escalation Rule is tripped.

### Law 5: Design and Spacing Discipline
All user interfaces must follow the "Supernova Aesthetics" spec. UI components must avoid generic frameworks and styles, using HSL curated color palettes, cinematic density, smooth animations, and high contrast.
