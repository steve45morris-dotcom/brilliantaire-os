# 🗺️ icy Command Map
`Version: 1.1.0` | `Status: Active`

Map of input arguments to specific operational engine executions.

- `icy start` ➔ Trigger Intent and Planning Engines.
- `icy status` ➔ Trigger Executive Briefing Engine.
- `icy context [task]` ➔ Trigger Context Builder and Mission Kit Engines.
- `icy build [feature]` ➔ Trigger Mission Engine.
- `icy audit` ➔ Trigger Repository Guardian and Review Engines.
- `icy review` ➔ Trigger Learning Engine.
