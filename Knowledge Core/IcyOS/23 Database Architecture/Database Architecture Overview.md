# 🌐 Database Architecture Overview
`Version: 1.0.0` | `Status: Active` | `Scope: Database Architecture`

This document details the Supabase PostgreSQL database configurations, extensions, and topologies of **IcyOS**.

---

## 🔌 Enabled Extensions
To support spatial search, text searches, and encryption inside Supabase:
- `uuid-ossp`: For automatic UUIDv4 key generation.
- `pg_trgm`: For fast text index search queries.
- `pgcrypto`: For credentials encryption.
