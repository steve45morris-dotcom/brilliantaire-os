# 🔍 ICOS Competitive Landscape
`Version: 1.0.0` | `Status: Active`

Analysis of competing products, focus domains, and differentiators.

---

## 🗺️ Competitive Mapping

- **Todoist / standard Task Managers**: Focus on manual list-building and checking boxes. Differentiator: IcyOS auto-decomposes and plans schedules via AI.
- **Motion / Calendar Schedulers**: Auto-arrange calendar events but lack code sandboxing, local voice pipelines, and documentation state tracking.
- **Unchecked AI Agents (Devin / Autonomous Workers)**: Run autonomously but introduce security and boundary errors. Differentiator: IcyOS enforces strict Human Approval gates.
