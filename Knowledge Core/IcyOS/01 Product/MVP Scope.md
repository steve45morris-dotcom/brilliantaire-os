# 📦 ICOS MVP Scope Spec
`Version: 1.0.0` | `Status: Active`

Boundaries and feature inclusion maps for the MVP v0.1 release.

---

## 🎯 In-Scope Features (MVP v0.1 Core Loop)
- **Input Ingestion**: Text capture and local voice bridge parsing.
- **AI Planning Engine**: Automatic decomposition of intents into checklist missions.
- **Timeline Engine**: Calendar slot assignment based on priority weights.
- **Approval Gate**: Human validation commands blocking unapproved scripts.

## 🚫 Out-of-Scope Features (Phase 2+)
- Native iOS application interface (Web App/PWA first).
- Complex automated multi-container cloud deployments.
- Wearable biometric synchronization.
