# 📖 Project Glossary: System Terminology
`Version: 1.0.0` | `Status: Active` | `Scope: Global`

This document details the core definitions, acronyms, and terminology used across the **IcyOS** ecosystem.

---

## 📚 Key Terms

- **Brain**: The Obsidian Knowledge Core. The permanent storage location of system state, design specifications, configurations, and plans.
- **Hands**: The local software Repository (`Repository/`). The implementation layer containing code, database migrations, servers, and tests.
- **Sovereign Stack**: The local-first, privacy-respecting toolset run locally on the developer's machine under direct human authorization.
- **Mission**: An isolated agent run package that encapsulates a specific set of tools, reference files, and target code locations to execute a task.
- **Protected Buffer**: Sacred time slots allocated for human developer rest or deep concentration that cannot be overwritten by scheduling engines.
- **Supernova**: The cyberpunk visual design language characterized by high contrast, curated HSL neon accents, and dark layouts.
- **VNP (Voice Narrative Protocol)**: The audio status bridge that enables agentic processes to speak their operational intents and completions vocally.
- **Sentinel**: The command security guardrail that scans terminal commands before execution to block dangerous patterns.
