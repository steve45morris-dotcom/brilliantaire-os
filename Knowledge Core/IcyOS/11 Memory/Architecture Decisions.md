`Version: 1.0.0` | `Status: Active` | `Scope: Global`

This document serves as the index and template guide for all Architecture Decision Records (ADRs) within the **IcyOS** ecosystem.

---

## 📂 ADR Template Layout
All files placed in the `13 Decisions/` folder must match this structural schema:

```markdown
# ADR-[ID]: [Title]
- **Status**: [Proposed / Accepted / Rejected / Deprecated]
- **Date**: [YYYY-MM-DD]
- **Author**: [Name / Role]

## Context & Problem
[Detail the architectural challenge, constraints, and requirements.]

## Proposed Solution
[Detail the chosen design, patterns, and component structures.]

## Consequences
- **Positive**: [Benefits of this approach]
- **Negative**: [Risks, constraints, or new dependencies introduced]
```
