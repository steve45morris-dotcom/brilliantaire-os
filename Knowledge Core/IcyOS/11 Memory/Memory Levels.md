# Memory Levels

## Level 1: Immutable

Founder Intent, Vision, Mission, and Principles.

Change rule: careful review required.

## Level 2: Strategic

Architecture, PRD, Roadmap, and AI Spec.

Change rule: update before implementation.

## Level 3: Operational

Current Sprint, Current State, Open Decisions, and Current Priority.

Change rule: changes often; keep current.

## Level 4: Historical

Research, Lessons, Meetings, Archives, and Session Summaries.

Change rule: append, do not erase history.
