# 🎨 Design System: The Supernova Spec
`Version: 1.0.0` | `Status: Active` | `Scope: Global`

This document outlines the premium visual guidelines, design tokens, animations, and color palettes for the **Supernova** aesthetic of **IcyOS**.

---

## 🌈 The Supernova Color Palette
Supernova uses high-contrast HSL Tailored Neon accents set against deep cinematic dark backdrops.

- **Background (Cinema)**: `hsl(240, 10%, 4%)`
- **Card Background (Glass)**: `hsla(240, 10%, 8%, 0.7)` (with `backdrop-filter: blur(12px)`)
- **Accent Primary (Neon Cyan)**: `hsl(180, 100%, 50%)`
- **Accent Secondary (Vibrant Purple)**: `hsl(275, 100%, 60%)`
- **Accent Warning (Neon Amber)**: `hsl(35, 100%, 50%)`
- **Text Primary**: `hsl(0, 0%, 98%)`
- **Text Secondary (Muted)**: `hsl(240, 5%, 65%)`

---

## 🔤 Typography & Layouts
- **Font Face**: Inter (default) or Outfit (for titles) loaded from Google Fonts.
- **Card Borders**: `1px solid hsla(240, 5%, 15%, 0.5)` with `box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.4)`.
