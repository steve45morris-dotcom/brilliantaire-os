# 🔏 Coding Standards: Formatting & Typings
`Version: 1.0.0` | `Status: Active` | `Scope: Engineering`

This document details the code formatting rules, import standards, and structural styles for IcyOS.

---

## 📐 Formatting Rules
- **Naming Conventions**:
  - Files: `kebab-case` for TypeScript components; `snake_case` for utility and automation scripts.
  - Variables and Functions: `camelCase`.
  - Classes and Interfaces: `PascalCase`.
- **Indentation**: 2 spaces (no tabs).
- **TypeScript**: Strict type definitions only. Avoid `any` types; utilize explicit type casting or interfaces.
