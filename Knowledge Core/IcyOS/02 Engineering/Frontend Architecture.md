# 💻 Frontend Architecture: Web App & PWA Specs
`Version: 1.0.0` | `Status: Active` | `Scope: Engineering`

This document details the frontend directories, client-side state managers, page layouts, and responsiveness strategies for the installable **IcyOS** web app.

---

## 🎨 Technology Stack
- **Framework**: Next.js App Router (v14+) paired with React 18+ for high-fidelity interactive views.
- **State Management**: Zustand for global client-side variables, React Query for server state caching.
- **Styling**: Tailwind CSS utilizing HSL curated design tokens for the **Supernova** visual aesthetic.
- **Progressive Web App (PWA)**: Enforces offline accessibility and service workers for rapid local loading. Native iOS is deferred to Phase 2.
