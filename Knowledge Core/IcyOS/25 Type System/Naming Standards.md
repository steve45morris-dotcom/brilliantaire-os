# 🔤 Naming Standards: Type System
`Version: 1.0.0` | `Status: Active` | `Scope: Type System`

Naming standards for TypeScript structures.

- **Interfaces**: Use `PascalCase` (e.g. `interface User`).
- **Enums**: Use `PascalCase` with uppercase values (e.g. `enum TaskPriority { P1 = 'P1' }`).
- **Types**: Use `PascalCase` for type aliases.
