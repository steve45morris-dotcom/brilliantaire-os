# 📐 Type Design Principles
`Version: 1.0.0` | \`Status: Active` | `Scope: Type System`

Principles guiding type declarations.

- **Strictness**: Enforces TS strict mode settings (`strict: true`).
- **Read-Only**: Domain entities are declared using `readonly` modifiers where immutable bounds apply.
- **Single Source of Truth**: Share interfaces between frontend client packages and backend runners.
