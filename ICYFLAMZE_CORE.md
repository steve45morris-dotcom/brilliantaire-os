# ICYFLAMZE CORE

## 🌌 Purpose
This document defines the core blueprint, universe direction, positioning, visual style guidelines, and execution mechanics for the creative project **ICYFLAMZE CORE** under the Brilliantaire OS multi-agent network.

## 📖 Official Project Definition
**ICYFLAMZE CORE** is a Street Scholar Futurist hip-hop universe that merges street intelligence with academic discipline, scientific thinking, philosophical depth, AI systems engineering, and music mythology. It serves as the creative intellectual property (IP) engine for Icyflamze, mapping narratives and artistic projects under an autonomous framework.

- **Approved Niche:** Street Scholar Futurism (blending street wisdom and cerebral/scientific themes; distinct from generic Afro-futurism)
- **Season 1 Working Title:** `ICYFLAMZE CORE: Rise of the Street Scholar`
- **Core Tagline:** *Street wisdom. Scientific mind. Futuristic soul.*

---

## 🎭 Character Identity: Icyflamze
Icyflamze is structured as an AI-era hip-hop founder, recording artist, systems architect, strategist, cultural systems builder, and legacy-driven creative technologist. He sits at the intersection of raw street experience and advanced technology, building the digital tools he uses to manifest his art.

---

## 🎨 Visual Language & Symbolism
The aesthetics are designed to evoke a premium, high-density cinematic atmosphere:
- **Core Palette:** Black, Gold, and Neon-Blue
- **Theme Style:** Anime Cyber / Street Scholar Futurist
- **Key Symbols:**
  - **Chess:** Strategy, tactical position play, long-term moves.
  - **Lighters:** Strike, creation, ignition under pressure, survival.
  - **Books & Formulas:** Scientific equations, academic rigors, deep philosophy.
  - **AI Panels:** Holographic control boards, agent systems, command lines.
  - **Soundwaves & City Pressure:** Heavy basslines, concrete stress, sonic resonance.
  - **Blue-Gold Flame:** The ultimate spark combining street heat and technological precision.

## 🛡️ Obsidian Staging Rule
To preserve vault integrity, **direct write actions to Obsidian vaults are strictly blocked by default** (`ALLOW_OBSIDIAN_DIRECT_WRITE = false`). All sync actions stage files to local staging directories first:
- Staged Note Destination: `outputs/icyflamze_core/obsidian_staging/`
- Write Gateway Destination: `outputs/write_staging/`

*Direct vault write requires manual review and the execution of the `npm run approve-write` command after review.*

## ⚙️ Command Usage
Execute Phase 14A commands via `npm run command -- "<command>"` or directly via their npm script entries:

```bash
# Print available commands
npm run command -- "icyflamze-core-help"

# Generate local project registry file
npm run command -- "icyflamze-core registry"

# Generate Obsidian staged note
npm run command -- "icyflamze-core obsidian-stage"

# Generate Season 1 summary report
npm run command -- "icyflamze-core season-summary"

# Generate integration sync report
npm run command -- "icyflamze-core sync-report"

# Check latest file generation statuses
npm run command -- "icyflamze-core status"
```
