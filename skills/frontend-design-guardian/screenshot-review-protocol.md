# Screenshot Review Protocol

Capture a stable desktop viewport and a representative mobile viewport, plus tablet and interactive states where practical. Record route, viewport, timestamp, build revision, state, and evidence path. Store screenshots outside tracked source folders by default. Compare baseline and revision at identical viewports. Review hierarchy, clipping, wrapping, alignment, imagery, focus, navigation, modal, and console state. Screenshot presence alone is not acceptance; each rubric score must cite what the evidence proves.
